# 智慧水务平台视觉系统

## 产品定位

面向水务分析人员、运维人员与算法工程师的桌面优先型工业数据平台。界面应当专业、冷静、可信，支持高信息密度，同时保持明确的任务层级和充足的可读性。

设计旋钮：`variance 3/10`、`motion 2/10`、`density 8/10`。

## 视觉原则

1. 信息优先：装饰不得压过数据、状态和操作。
2. 水务语义：蓝色代表平台与信息，青绿色代表正常和水务对象，琥珀色代表关注，红色只代表失败或高风险。
3. 稳定边界：悬停、按下和选中不改变组件尺寸，不产生布局抖动。
4. 层级来自表面、边框、间距和字号，不依赖大面积阴影。
5. 色彩不是唯一状态信号；状态同时使用文字、图标、线型或形状。

## 字体与数字

- 中文与界面正文：`Inter, "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`。
- 不引入网络字体；不使用圆体或等宽字体作为中文标题。
- 标题层级：32 / 24 / 20 / 16 px；正文：14 px；辅助信息：12 px。
- 指标、时间和表格数字使用 `font-variant-numeric: tabular-nums`。
- 正文行高 1.55，说明文字行高 1.65。

## 色彩语义

- `primary`：平台主操作与焦点，水务深蓝。
- `secondary`：水务对象、正常趋势与辅助强调，青绿。
- `accent`：选中、人工关注和警示，琥珀色。
- `surface`：页面、卡片、浮层和画布按四级表面区分。
- `danger`：失败、删除和高风险；不得用于普通强调。
- 所有正文对当前表面至少保持 4.5:1 对比度，控件边界与有意义图标至少 3:1。

## 空间、圆角与阴影

- 采用 4px 基准间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 页面常规间距 24px；数据密集区域 12–16px；移动端页面边距 14–16px。
- 控件圆角 8–10px，卡片 12–16px，胶囊状态使用 999px。
- 默认卡片只使用边框与极轻阴影；浮层和侧滑详情使用中等阴影。

## 组件规则

- 主按钮每个操作区最多一个；危险操作不与主按钮使用相同填充样式。
- 图标统一使用本地 SVG 线性图标，16 / 18 / 20 / 24px 四档，不使用 emoji 充当结构图标。
- 表格表头固定使用弱表面色；行悬停与选中使用不同强度的主色背景。
- KPI 卡片必须展示名称、值和单位或上下文，不用孤立的大数字。
- 空状态说明下一步；加载状态保持布局尺寸，避免内容跳动。
- 弹窗必须具备标题、关闭按钮、键盘焦点和明确的主次操作。

## 动效

- 快速反馈 120ms，普通过渡 180ms，面板进入 220ms。
- 仅动画透明度、颜色、阴影和小距离位移；避免大面积缩放和滚动编排。
- `prefers-reduced-motion: reduce` 下关闭非必要动画并立即显示最终状态。

## 图表与拓扑

- 实测值使用深蓝实线，预测值使用青色虚线，置信区间使用同色 12–18% 透明填充。
- 异常点同时使用高对比圆点、边框和文本标记，不只改变颜色。
- 拓扑默认边为中性灰蓝；当前路径为主蓝；候选管段为琥珀；高风险为红色。
- 多序列除颜色外还使用线型、点形和直接标签；超过六条序列时默认聚合或筛选。
- 图表保留缩放、复位和文字摘要；实时更新必须允许暂停。

## 响应式与可访问性

- 验收宽度：1440、1024、768、390px。
- 侧栏在窄屏转为覆盖式抽屉，内容不得被固定栏遮挡。
- 所有操作支持键盘，焦点环清晰；拖拽功能提供菜单或按钮替代。
- 独立图标按钮必须有可访问名称；装饰图标使用 `aria-hidden="true"`。

## 禁止事项

- 不引入另一套 CSS 框架替代 Angular Material。
- 不用大面积玻璃拟态、霓虹渐变、3D 装饰或持续循环动画。
- 不在单个页面重新定义完整的按钮、字体和状态颜色体系。
- 不为视觉改造改变 API、业务状态和既有操作语义。
