# 管网漏损闭环研判页面覆盖规则

- 页面名称保持场景无关；具体小区只作为当前数据场景标签，不进入功能名称。
- 保持 8/10 数据密度，首屏任务顺序是“真实数据解析摘要 → 全管网时空态势 → 八步分析 → 当前步骤证据”。
- 三维管网和全局时间轴是长期上下文。切换阶段不得重建场景，也不得重置时间、资产选择或摄像机。
- 八个步骤是可点击的分析导航。选中、完成和待分析状态同时使用文字、边框与序号表达；点击待分析阶段应说明缺少的结果，不能展示模拟进度。
- 分析图层通过 `available_after_stage` 渐进开放；待分析图层继续可见但不可选择，并说明解锁阶段。
- 资产检查器稳定划分为概览、时序、证据、相邻对象；基础拓扑载入后即可查看概览，其余内容随真实分析结果开放。
- 时间轴提供上一时刻、下一时刻和播放/暂停；悬停、键盘聚焦或 `prefers-reduced-motion` 时停止自动播放。
- KPI 使用等宽数字并标明单位，风险类指标使用琥珀或红色，普通结果使用主色或青色。
- 加载状态维持场景和结果区域尺寸，使用 `aria-busy`/`role=status`，短请求不得人为延迟或伪造阶段进度。
